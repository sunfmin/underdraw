WHEN
  After `underdraw check` answers "ok": true, to see the screen: show the
  PNG to the person to settle what it should look like, and read the node
  boxes to know where each part went. Render each fixture and phase that
  matters, at a phone width (390) and a desktop width (1120).

WHO
  The agent that writes the description, for the person it works with.

READS
  <path>/screen.json and, beside it, tokens.json (spaces, radii, fonts,
  breakpoints) and kinds.json when there is one (what the project's own
  kinds look like). Refuses a description `check` finds faults in.

WRITES
  One PNG: --out, or <dir>/renders/<fixture or phase>-<width>.png. Running
  it again overwrites the same file.

ANSWERS
  {
    "png":        the file written
    "state":      {"fixture": name} or {"phase": name}
    "breakpoint": "compact" or "regular", chosen by tokens' breakpoints and --width
    "width", "height": the page in points; the page is as tall as its content
    "scale":      pixels per point (lowered when the page is taller than the GPU draws)
    "pixels":     [width, height] of the PNG
    "nodes":      [{"id", "kind", "box": {"x", "y", "width", "height"} in points,
                    "label": the number tagged on it in the picture, or null,
                    "assumed": what the agent guessed there, or that its kind is
                      not one underdraw knows, or null}, …]
  }

WHAT YOU SEE
  A wireframe, in grays: boxes, text in the system font, crossed boxes for
  images. A dark numbered circle tags everything a person can act on, in
  document order; the same number is "label" in nodes, so "3" in a
  conversation means one node. What a dialog (an opaque box pinned over
  the page) or its backdrop covers gets no number, and its "label" is null. An orange
  dashed outline and "?" mark what was assumed, for the person to confirm,
  and a kind underdraw does not know, drawn as a box with its name. Icons
  are Material Symbols, drawn outlined, or solid for a name ending in .fill.

WHAT TRIPS YOU UP
  - Needs a GPU (Metal on macOS); `underdraw doctor` says whether there is one.
  - The page shows everything at once: a sticky bar is drawn at the end of
    the page, not over the content.
